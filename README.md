- **Tech:** React, Vite, Tailwind CSS, LocalStorage
- [View Repository](https://github.com/zlati-dev/receipt-manager)

A modern weather forecast application with a built-in calculator. Fetches real-time weather data from the OpenWeatherMap API with a sleek glassmorphism design.

- **Tech:** React, Vite, Tailwind CSS v4, OpenWeatherMap API
- [View Repository](https://github.com/zlati-dev/react-tailwind-weather)

My personal portfolio website featuring a dark/light theme toggle, multi-page routing, and a contact form.

- **Tech:** React, Vite, React Router, CSS
